# Diretório `/test` — Testes

## Objetivo

Este diretório é destinado a testes unitários e de integração do firmware, utilizando o framework de testes do PlatformIO (Unity).

## Conteúdo

| Arquivo | Responsabilidade |
|---|---|
| `README` | Guia original do PlatformIO sobre estrutura de testes. |

> **Nota:** Testes serão adicionados conforme a necessidade de validação automatizada dos módulos.

## Dependências / Relações

Os testes validam o comportamento dos módulos em `/src` e `/include`, garantindo que os critérios de aceitação (CA-01 a CA-04) definidos em `/doc/specification.md` são atendidos.
